Đổi PDF sang ảnh JPG, PNG

Công cụ này đổi mỗi trang của file PDF thành một ảnh JPG hoặc PNG, ngay trong trình duyệt và không tải file lên mạng. Thầy cô dùng để đăng đề, phiếu bài tập lên Zalo, nhóm phụ huynh hoặc chèn vào bài giảng.

Chọn việc cần làm

1. Chọn file PDF

2. Ảnh xuất ra

PDF sang ảnh

Mỗi trang của file PDF thành một ảnh JPG hoặc PNG, để đăng Zalo, gửi nhóm phụ huynh hoặc chèn vào bài giảng. Có thể chọn chỉ vài trang.

Mọi file chỉ được xử lý ngay trên máy bạn, không tải lên mạng.

Cần việc khác với file PDF? Xem thêm watermark và đánh số trang, ghép nhiều trang trên một tờ A4, hoặc ảnh sang PDF, ghép, tách, xoay trang.

Cách dùng nhanh

  1. Bấm “Chọn file PDF” và chọn file cần đổi. Công cụ báo file có bao nhiêu trang.
  2. Chọn JPG (nhẹ) hoặc PNG (nét hơn), rồi chọn cạnh dài nhất của ảnh: 1200, 1800 hoặc 2600 px.
  3. Muốn đổi vài trang thì gõ số trang, ví dụ 1-3, 5. Để trống là đổi tất cả các trang.
  4. Bấm “Chuyển thành ảnh”, xem các ảnh vừa tạo rồi bấm “Tải” ở từng ảnh hoặc “Tải tất cả (ZIP)”.

Gợi ý sử dụng

  • Đăng đề kiểm tra hoặc phiếu bài tập lên Zalo, nhóm phụ huynh dưới dạng ảnh, ai mở cũng xem được ngay.
  • Lấy một trang sách hoặc đề PDF làm ảnh nền cho bài giảng và slide.
  • Cắt riêng vài trang cần dùng thành ảnh thay vì gửi cả file PDF dài.

Mẹo và lưu ý

  • Chọn 1800 px để đọc rõ chữ in trên khổ A4, chọn 2600 px nếu định in ảnh ra giấy.
  • Chữ trong ảnh không còn chọn hay sao chép được như trong PDF. Hãy giữ lại file PDF gốc.
  • File PDF dài hàng trăm trang nên đổi từng đợt vài chục trang để trình duyệt không bị đơ.
  • Lần đầu dùng, trình duyệt tải thêm thành phần đọc PDF khoảng 1,8 MB nên có thể chờ vài giây.

Câu hỏi thường gặp

Làm sao đổi file PDF thành ảnh?

Chọn file PDF, chọn JPG hoặc PNG và kích thước ảnh, rồi bấm “Chuyển thành ảnh”. Mỗi trang thành một ảnh, tải riêng từng ảnh hoặc cả bộ trong một file ZIP. Muốn đổi vài trang thì gõ số trang, ví dụ 1-3, 5.

Nên chọn JPG hay PNG?

Chọn JPG khi cần file nhẹ để gửi qua Zalo hoặc email. Chọn PNG khi trang có chữ nhỏ và đường kẻ mảnh cần nét hơn, nhưng file sẽ nặng hơn nhiều.

Đổi PDF sang ảnh có bị giảm chất lượng không?

Có một phần, vì ảnh là điểm ảnh cố định còn PDF thì phóng to không vỡ. Cạnh dài 1800 px đủ đọc rõ chữ in trên khổ A4, chọn 2600 px nếu định in ảnh ra giấy. Chữ trong ảnh không còn chọn hay sao chép được, nên hãy giữ lại file PDF gốc.

File PDF của tôi có bị tải lên mạng không?

Không. Việc đổi chạy ngay trên máy thầy cô và hoclieu.app không nhận file nào. Lần đầu dùng, trình duyệt tải thêm một thành phần đọc PDF khoảng 1,8 MB từ chính web này.

Có đổi được PDF đặt mật khẩu hoặc PDF sang Word không?

Chưa. File PDF đặt mật khẩu phải mở khoá bằng phần mềm đọc PDF trước rồi mới đưa vào đây. Công cụ cũng chưa đổi PDF sang Word, vì giữ đúng bố cục thường cần máy chủ xử lý, trái với cách làm của web là giữ file trên máy bạn.
